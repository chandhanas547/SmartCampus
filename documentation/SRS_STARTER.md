# Smart Campus — SRS Starter

## Purpose
A campus portal for admins, faculty and students.

## Users
Admin, Faculty, Student.

## Implemented Requirements
Login; dashboard; student creation and deletion; course creation and enrollment; attendance; assignments; announcements.

## Non-functional Requirements
Responsive UI, access control, hashed passwords, basic request rate limiting.

## Limitations
Local JSON storage, demonstration credentials, no production deployment hardening.

## Future Scope
MongoDB, grading, faculty CRUD, profile settings, reporting and automated testing.
